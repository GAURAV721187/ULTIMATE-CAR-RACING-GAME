# 🚗 ULTIMATE CAR RACING GAME

A fast-paced and addictive car racing game built using Python and Pygame.  
Dodge traffic, survive longer, and test your reflexes in this endless racing challenge! 🏁

---

## 🎮 Features
- Smooth and responsive controls
- Endless gameplay mode
- Increasing difficulty over time
- Lightweight and fun to play

---

## 🕹️ Controls
- ⬅️ Left Arrow – Move Left  
- ➡️ Right Arrow – Move Right  

---

## ▶️ How to Run

1. Install Python (if not installed)
2. Install pygame:.

---

## 💡 About
This game is created as a fun project to practice game development using Python.

---

🔥 Enjoy the game and try to beat your high score!
